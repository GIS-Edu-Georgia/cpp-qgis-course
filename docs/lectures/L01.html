ლექცია 01 · შესავალი

რუკა: Python-იდან C++-მდე

The map — from Python to C++

PyQGIS როგორც C++ API-ს სარკე · QGIS-ის არქიტექტურა · პირველი C++ პროგრამა

ამ კურსის მიზანია, PyQGIS-ის „კოპირება-ჩასმის“ დონიდან გადავიდეთ იქამდე, რომ QGIS-ის C++ დოკუმენტაცია (api.qgis.org) გვესმოდეს და საკუთარი კოდი QGIS-ის ბირთვთან ერთად შევკრათ. ყველა მაგალითი გეოგრაფიულ მასალაზეა აგებული: ფენები, ობიექტები, კოორდინატები, ფართობები.

01.1 · შესავალი

PyQGIS არის C++-ის სარკე

PyQGIS ცალკე ბიბლიოთეკა არ არის. QGIS-ის ბირთვი C++-ზეა დაწერილი, Python-ის კლასები კი ავტომატურად გენერირდება (SIP-ის საშუალებით) იმავე C++ კლასებიდან. ამიტომ სახელები და ლოგიკა ერთი და იგივეა: QgsVectorLayer, QgsFeature, QgsGeometry.

გზამკვლევი ორ ენაზე

წარმოიდგინე საქართველოს რუკა ორ ენაზე. ქალაქები და გზები ერთი და იგივეა, განსხვავდება მხოლოდ წარწერების ენა. PyQGIS არის „ქართული წარწერებით“ რუკა, C++ API — „ორიგინალის“.

საბოლოოდ, თუ PyQGIS-ში იცი რა უნდა გააკეთო, C++-ში ახალი ლოგიკა კი არ გჭირდება, არამედ ახალი გრამატიკა: ტიპები, მაჩვენებლები, კომპილაცია.

01.2 · შესავალი

QGIS-ის არქიტექტურა

QGIS-ის წყარო კოდი რამდენიმე ბიბლიოთეკადაა დაყოფილი:

საქაღალდე ბიბლიოთეკა რას შეიცავს გეო-მაგალითი
src/core/ qgis_core გეომეტრია, CRS, ფენები, ატრიბუტები, რენდერი QgsGeometry, QgsCoordinateReferenceSystem
src/gui/ qgis_gui ვიჯეტები და დიალოგები ფენის არჩევის კომბობოქსი
src/analysis/ qgis_analysis გეოპროცესინგი და ანალიზი ბუფერი, გადაკვეთა
src/app/ qgis თავად დესკტოპ პროგრამა მენიუ, ინსტრუმენტთა პანელი
დაიმახსოვრე

core არ იცნობს ინტერფეისს, gui კი core-ს ეყრდნობა. ამიტომაც შეგიძლია core ფანჯრების გარეშე, სერვერზეც გამოიყენო.

01.3 · შესავალი

ერთი და იგივე ამოცანა ორ ენაზე

ამოცანა: ფენის ყველა ობიექტის სახელის გამოტანა.

რა არის იგივე: getFeatures, attribute. რა არის ახალი: ტიპების სახელები (QgsVectorLayer), * ნიშანი, ; ყოველი ხაზის ბოლოს, qobject_cast. თითოეულს ამ კურსში ცალკე გავარჩევთ.

01.4 · შესავალი

პირველი C++ პროგრამა

C++ პროგრამა კომპილდება: წყარო კოდს კომპილატორი გადააქცევს მანქანურ ფაილად, რომელსაც შემდეგ ვუშვებთ. Python-ში ეს ეტაპი არ გვქონდა.

ნაწილები

#include ჩართავს ბიბლიოთეკას, main() არის პროგრამის შესასვლელი წერტილი, std::cout გამოიტანს ტექსტს ეკრანზე.

01.5 · შესავალი

Python vs C++ ერთი შეხედვით

Python / PyQGIS C++ / QGIS Core
გაშვება ინტერპრეტატორი, პირდაპირ კომპილაცია, შემდეგ გაშვება
ტიპები დინამიური: x = 5 სტატიკური: int x = 5;
მეხსიერება ავტომატური ხელით, ან smart pointer-ებით
შეცდომები გაშვების დროს უმეტესად კომპილაციისას
სიჩქარე მოხერხებული მაღალი
კოდის დაცვა .py ღია ტექსტია შედეგი ბინარულია
01.6 · შესავალი

სავარჯიშო და შეჯამება

სავარჯიშო
  1. გახსენი api.qgis.org და მოძებნე კლასი QgsFeature. ჩამოწერე სამი მეთოდი, რომლებიც PyQGIS-იდან უკვე იცი.
  2. დაწერე და გაუშვი „Hello“ პროგრამა, ოღონდ გამოიტანე შენი ქალაქის სახელი.
  3. დაამატე მეორე ხაზი: Population: 1100000 (თბილისის მიახლოებითი მოსახლეობა).
შეჯამება
  • PyQGIS და C++ API ერთი და იგივე კლასებია სხვადასხვა „გრამატიკით“.
  • core — ლოგიკა, gui — ინტერფეისი, app — პროგრამა.
  • C++ კოდი იკომპილება და მკაცრად ტიპიზირებულია.
