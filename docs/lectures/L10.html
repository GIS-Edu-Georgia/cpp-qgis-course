10.1 · Qt

QString

QString არის Unicode ტექსტი, ამიტომ ქართული ასოებიც პრობლემის გარეშე მუშაობს.

ოპერაცია Python Qt
სიგრძე len(s) s.length()
ნაწილი s[2:5] s.mid(2, 3)
ჩანაცვლება s.replace(a, b) s.replace(a, b)
ფორმატირება f"{a}: {b}" QString("%1: %2").arg(a).arg(b)
რიცხვად int(s) s.toInt(), s.toDouble()
std::string-ში s.toStdString()
ქართული და std::string

toStdString() UTF-8-ს აბრუნებს. კონსოლში ქართული ტექსტი მხოლოდ მაშინ გამოჩნდება სწორად, თუ ტერმინალი UTF-8-ზეა. qDebug()-ით დაბეჭდვისას ტექსტი ბრჭყალებშია ("..."), qDebug().noquote() კი ბრჭყალებს გაუქმებს.

10.2 · Qt

QList

QList<T> არის Qt-ის დინამიური მასივი, std::vector-ის ძმა.

გამოძახება append, size(), [], contains(). QGIS-ში ფენების სია არის QList<QgsMapLayer *>, მაგალითად QgsProject::mapLayersByName(...) სწორედ ამას აბრუნებს.

10.3 · Qt

QVariant — უნივერსალური ყუთი

QVariant ერთ მნიშვნელობას ინახავს ნებისმიერი ტიპისას: რიცხვი, ტექსტი, თარიღი, ან „არაფერი“ (NULL).

დაიმახსოვრე

QVariant არ „იცის“ წინასწარ, რა ტიპია შიგნით, ამიტომ კითხვისას თავად ვირჩევთ toInt(), toString(), toDouble(). თუ გარდაქმნა შეუძლებელია, შედეგი ნულოვანი ან ცარიელია.

10.4 · Qt

QgsAttributes — ატრიბუტების ცხრილის ერთი სტრიქონი

ახლა გასაგებია QgsAttributes გვერდი, რომლითაც კურსი დაიწყო. ეს კლასი არის QVariant-ების მიმდევრობა: ფენის ცხრილის ერთი ჩანაწერი. თითოეული ელემენტი ერთი ველის მნიშვნელობაა.

10.5 · Qt

QObject-ის ხე

QObject-ები მშობელ-შვილის ხეში ცხოვრობენ. როცა მშობელი იშლება, თავის შვილებსაც წაშლის. ამიტომ Qt-ში ხშირად new გვხვდება delete-ის გარეშე.

10.6 · Qt

signals და slots

signal არის „რაღაც მოხდა“, slot — „ამაზე რეაგირება“. connect მათ აკავშირებს.

ან lambda-თი, დამატებითი მეთოდის გარეშე:

საფოსტო ყუთი

signal არის ზარის ხმა კარზე: ის არავის ეუბნება, ვინ გაიგონებს. slot არის ის, ვინც ზარზე რეაგირებს. connect ამათ ერთმანეთს აკავშირებს და გამომგზავნს მიმღები არ აინტერესებს.

PyQGIS-ში იგივეა: layer.selectionChanged.connect(handler).

10.7 · Qt

სავარჯიშო და შეჯამება

სავარჯიშო
  1. შექმენი QList<QVariant> ფენის ჩანაწერისთვის: სახელი (ტექსტი), მოსახლეობა (int), ფართობი (double). დაბეჭდე თითოეული ელემენტი.
  2. შექმენი QMap<QString, QVariant> იგივე მონაცემით და გამოიტანე ველი სახელით.
  3. წაიკითხე QgsFeature::attribute მეთოდი api.qgis.org-ზე და ჩამოწერე მისი ორი ვარიანტი.
შეჯამება
  • QString = Unicode ტექსტი, QList<T> = მასივი, QVariant = უნივერსალური მნიშვნელობა.
  • QgsAttributes = QVariant-ების მიმდევრობა.
  • QObject ხე თავად ასუფთავებს შვილებს.
  • signal/slot აკავშირებს „მოხდა“ და „რეაგირება“ ერთმანეთს.
