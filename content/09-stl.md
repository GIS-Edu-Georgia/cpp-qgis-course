გეო-მონაცემებთან მუშაობისას ბევრი ერთგვაროვანი მონაცემი გვაქვს: მრავალკუთხედის წვეროები, ფენის ობიექტები, რეგიონების მოსახლეობა. მათ შესანახად გვჭირდება **კონტეინერი**: ობიექტი, რომელიც ბევრ მნიშვნელობას ინახავს. მასზე ოპერაციების (დალაგება, ძებნა, ჯამი) შესასრულებლად კი **ალგორითმები** არსებობს.

**STL** (Standard Template Library) არის C++-ის სტანდარტული ბიბლიოთეკა სწორედ ამ კონტეინერებისა და ალგორითმებისთვის. QGIS ძირითადად Qt-ის კონტეინერებს იყენებს (თავი 10), მაგრამ STL-ის ცოდნა მაინც აუცილებელია: ორივეს ლოგიკა ერთია და ბევრი QGIS ფუნქცია STL ტიპებს აბრუნებს.

## vector — დინამიური მასივი

`std::vector<T>` არის სია: ერთმანეთის გვერდით მოთავსებული ელემენტები, რომლებსაც ნომრებით (ინდექსებით, 0-დან) მივწვდებით და რომელიც საჭიროებისას იზრდება. კუთხურ ფრჩხილებში `<double>` წერია ელემენტის ტიპი: `std::vector<double>` არის „დიდი რიცხვების სია“, `std::vector<Point>` — „წერტილების სია“. ერთ სიაში ყველა ელემენტი ერთი ტიპისაა.

თუ Python-ს იცნობ, ის `list`-ის ანალოგია:

::: compare
```python
areas = [12.5, 7.0, 30.5, 4.0]
areas.append(9.0)
print(len(areas))
for a in areas:
    print(a)
```

```cpp
std::vector<double> areas = {12.5, 7.0, 30.5, 4.0};
areas.push_back(9.0);
std::cout << areas.size() << "\n";
for (double a : areas) {
  std::cout << a << "\n";
}
```
:::

| ოპერაცია | Python | C++ |
|---|---|---|
| დამატება | `append(x)` | `push_back(x)` |
| ზომა | `len(a)` | `a.size()` |
| ელემენტი | `a[0]` | `a[0]` |
| ბოლო | `a[-1]` | `a.back()` |
| გასუფთავება | `a.clear()` | `a.clear()` |

::: tip წესი
დიდი ელემენტების ციკლში გამოიყენე `const auto &`: `for (const auto &feature : features)`. ასე ელემენტი არ დაკოპირდება (თავი 05).
:::

## map — გასაღები → მნიშვნელობა

`std::map<K, V>` ინახავს წყვილებს „გასაღები → მნიშვნელობა“, მაგალითად „ქალაქი → მოსახლეობა“. გასაღებით მნიშვნელობას სწრაფად ვპოულობთ, გასაღებებს კი კონტეინერი ავტომატურად ალაგებს ზრდადობით (Python-ის `dict`-ის მსგავსია). კუთხურ ფრჩხილებში ორი ტიპია: გასაღებისა და მნიშვნელობის.

```cpp map.cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> population = {
        {"Tbilisi", 1200000},
        {"Batumi", 170000},
        {"Kutaisi", 147000},
    };

    population["Rustavi"] = 125000;

    for (const auto &[city, people] : population) {
        std::cout << city << ": " << people << "\n";
    }
    return 0;
}
```

```output
Batumi: 170000
Kutaisi: 147000
Rustavi: 125000
Tbilisi: 1200000
```

`std::map` გასაღებებს **დალაგებულად** ინახავს. თუ დალაგება არ გჭირდება და მხოლოდ სწრაფი ძებნა გაინტერესებს, არსებობს `std::unordered_map`: მისი ელემენტების თანმიმდევრობა წინასწარ განსაზღვრული არ არის.

ახსნა: `population["Rustavi"] = 125000;` ამატებს ახალ წყვილს. ციკლში `for (const auto &[city, people] : population)` ყოველი წყვილიდან ორივე ნაწილს ცალ-ცალკე ვიღებთ (`city` და `people`); ეს ჩანაწერი C++17-ის სიახლეა და მას **structured binding** ჰქვია. `const auto &` კი ნიშნავს „ტიპი თვითონ გამოიცანი, არ დააკოპირო და არ შეცვალო“ (თავი 05).

::: note
მოსახლეობის რიცხვები აქ მიახლოებითი და საილუსტრაციოა, მიზანი კონტეინერის ჩვენებაა.
:::

::: warn
`population["Poti"]` — თუ გასაღები არ არსებობს, `map` ჩუმად შექმნის ახალ ჩანაწერს ნულოვანი მნიშვნელობით. არსებობის შესამოწმებლად გამოიყენე `population.find("Poti") != population.end()` ან `population.count("Poti")`.
:::

## ალგორითმები

`<algorithm>` და `<numeric>` გვაძლევს მზა ოპერაციებს: დალაგება, დათვლა, ჯამი.

```cpp algo.cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<double> areas = {12.5, 7.0, 30.5, 4.0};

    std::sort(areas.begin(), areas.end(),
              [](double a, double b) { return a > b; });

    for (double a : areas) std::cout << a << " ";
    std::cout << "\n";

    double total = std::accumulate(areas.begin(), areas.end(), 0.0);
    std::cout << "Total: " << total << "\n";
    std::cout << "Average: " << total / areas.size() << "\n";

    long big = std::count_if(areas.begin(), areas.end(),
                             [](double a) { return a > 10.0; });
    std::cout << "Parcels > 10 ha: " << big << "\n";
    return 0;
}
```

```output
30.5 12.5 7 4 
Total: 54
Average: 13.5
Parcels > 10 ha: 2
```

ახსნა: ალგორითმები სიას **დიაპაზონის** სახით იღებენ: `areas.begin()` არის დასაწყისი, `areas.end()` — „ბოლოს მერე“. `std::sort` ალაგებს; მესამე არგუმენტი ამბობს, როგორ შევადაროთ ორი ელემენტი (აქ „უფრო დიდი წინ იყოს“, ამიტომ დალაგება კლებადია). `std::accumulate` აჯამებს (დაწყება `0.0`-დან). `std::count_if` ითვლის, რამდენი ელემენტი აკმაყოფილებს პირობას.

## lambda — უსახელო ფუნქცია

`[](double a, double b) { return a > b; }` არის lambda: პატარა ფუნქცია, რომელიც ადგილზევე იწერება და სახელი არ სჭირდება. `[]` არის დასაწყისი, შემდეგ პარამეტრები, შემდეგ ფუნქციის სხეული. (Python-ში ეს `lambda a, b: a > b`-ს ჰგავს.) `[]` კვადრატულ ფრჩხილებში შეიძლება გარე ცვლადების „დაჭერა“:

```cpp
double limit = 10.0;
auto isBig = [limit](double a) { return a > limit; };
```

QGIS-ში lambda-ებს ხშირად გამოიყენებენ signal-ებთან დასაკავშირებლად (თავი 10).

## ძებნა

```cpp
auto it = std::find_if(areas.begin(), areas.end(),
                       [](double a) { return a > 20.0; });
if (it != areas.end()) {
    std::cout << "First > 20: " << *it << "\n";
}
```

`find_if` აბრუნებს **iterator-ს**: ელემენტზე მიმთითებელს (მაჩვენებლის მსგავს ობიექტს). თუ ელემენტი ვერ მოიძებნა, შედეგი უდრის `areas.end()`-ს, ამიტომ `*it`-ს გამოყენებამდე ეს ყოველთვის უნდა შევამოწმოთ (როგორც `nullptr` მაჩვენებელზე). იგივე ეხება `std::max_element`-ს: ცარიელ სიაზე ის `end()`-ს აბრუნებს. `*it` იღებს მნიშვნელობას.

::: warn ცარიელი კონტეინერი
`std::accumulate` ცარიელ სიაზე საწყის მნიშვნელობას (`0.0`) დააბრუნებს, ხოლო საშუალოს გამოთვლისას `total / areas.size()` ნულზე გაყოფა იქნება. ამიტომ გაყოფამდე ყოველთვის შეამოწმე `if (!areas.empty())`.
:::

::: note QgsFeatureIterator STL-ის კონტეინერი არ არის
QGIS-ში `QgsFeatureIterator` ამავე იდეაზეა აგებული (ობიექტებს სათითაოდ გვაწვდის), მაგრამ ის STL-ის კონტეინერი არ არის: ობიექტები მეხსიერებაში წინასწარ არ ინახება, ისინი მონაცემთა პროვაიდერიდან (ფაილიდან ან ბაზიდან) წამოდის და მხოლოდ ერთხელ გავივლით. ამიტომ მას `begin()`/`end()` და STL ალგორითმები ჩვეულებრივ არ აქვს; იყენებენ `nextFeature(...)` ციკლს.
:::

## სავარჯიშო და შეჯამება

::: exercise სავარჯიშო
1. დაწერე `std::vector<Point>` ხუთი წერტილით და `std::sort`-ით დაალაგე x-ის მიხედვით.
2. შექმენი `std::map<std::string, double>`: მდინარე → სიგრძე კმ-ში (`{"Mtkvari", 1364}`, `{"Rioni", 327}`, `{"Alazani", 407}`). იპოვე ყველაზე გრძელი (`std::max_element` მიმართე დოკუმენტაციას).
3. `count_if`-ით დათვალე მდინარეები, რომლებიც 400 კმ-ზე გრძელია.
:::

::: summary შეჯამება
- `vector` = list, `map` = dict, ორივე ტიპიზებულია.
- ალგორითმები იღებენ დიაპაზონს `begin()`–`end()` და lambda-ს.
- iterator — მაჩვენებლის მსგავსი ობიექტი კონტეინერში გადასაადგილებლად.
:::
