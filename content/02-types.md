ამ თავში ვისწავლით, როგორ ვინახავთ მონაცემებს პროგრამაში: კოორდინატებს, ობიექტების რაოდენობას, ფენის სახელს. ეს ყველაფრის საფუძველია: QGIS-ის კოდში ყოველი ხაზი რაღაც მონაცემს ინახავს ან გადააქვს.

## რა არის ცვლადი

**ცვლადი** (variable) არის კომპიუტერის მეხსიერებაში დაკავებული ადგილი, რომელსაც სახელი აქვს და რომელშიც მონაცემს ვინახავთ. სახელით შემდეგ ამ მონაცემს ვპოულობთ და ვცვლით.

::: analogy ყუთი და ეტიკეტი
ცვლადი ეტიკეტიანი ყუთია. ეტიკეტზე წერია სახელი (`lat`), ყუთში კი რაღაც მნიშვნელობა დევს (`41.7151`). ყუთის ფორმა განსაზღვრავს, რა ჩაეტევა შიგნით: ერთში მხოლოდ მთელი რიცხვი, მეორეში ათწილადი, მესამეში ტექსტი.
:::

C++ **მკაცრად ტიპიზებული** ენაა: ყუთის ფორმას (**ტიპს**) წინასწარ ვწერთ. ამით კომპილატორმა იცის, რამდენ მეხსიერებას დაუთმოს ცვლადს და რა მოქმედებებია დასაშვები. ტიპის გარეშე ცვლადი არ შეიქმნება.

## ცვლადის შექმნა

ცვლადის შექმნას **გამოცხადება** ჰქვია. ფორმულა მარტივია:

```
ტიპი  სახელი  =  საწყისი_მნიშვნელობა;
```

```cpp
double lat = 41.7151;       // ათწილადი რიცხვი
int vertexCount = 12;       // მთელი რიცხვი
bool isValid = true;        // ჭეშმარიტი ან მცდარი
```

- `double`, `int`, `bool` — ტიპები;
- `lat`, `vertexCount`, `isValid` — ჩვენ მიერ არჩეული სახელები;
- `=` — „ჩაწერე ამ ყუთში“ (მინიჭება, არა მათემატიკური ტოლობა);
- `;` — ინსტრუქციის დასასრული;
- `//` — **კომენტარი**: ტექსტი, რომელსაც კომპილატორი უგულებელყოფს და რომელიც მხოლოდ ადამიანისთვისაა.

::: note სახელდების წესები
სახელი შეიძლება შეიცავდეს ასოებს, ციფრებს და `_`-ს, მაგრამ ციფრით არ იწყება (`2lat` არასწორია). რეგისტრი მნიშვნელოვანია: `Lat` და `lat` სხვადასხვა ცვლადია. QGIS-ში სახელებს წერენ „აქლემის“ სტილით: `vertexCount`, `isValid`, ანუ პირველი სიტყვა პატარაა, შემდეგი სიტყვები დიდი ასოთი იწყება.
:::

თუ Python-ს იცნობ, შედარებისთვის:

::: compare
```python
lat = 41.7151
vertex_count = 12
is_valid = True
```

```cpp
double lat = 41.7151;
int vertexCount = 12;
bool isValid = true;
```
:::

## ძირითადი ტიპები

| ტიპი | რას ინახავს | გეო-მაგალითი |
|---|---|---|
| `int` | მთელი რიცხვი | `int vertexCount = 12;` |
| `double` | ათწილადი (მაღალი სიზუსტით) | `double lat = 41.7151;` |
| `bool` | `true` ან `false` | `bool isValid = true;` |
| `char` | ერთი სიმბოლო | `char hemisphere = 'N';` |
| `std::string` | ტექსტი | `std::string city = "Batumi";` |
| `qint64` (Qt-ის ტიპი) | ძალიან დიდი მთელი რიცხვი | ფენაში მილიონობით ობიექტი |

`int` დაახლოებით ±2 მილიარდამდე რიცხვს იტევს, ამიტომ ძალიან დიდი რაოდენობებისთვის (ობიექტების რაოდენობა დიდ ფენაში) QGIS იყენებს `qint64`-ს. ტექსტის ტიპს, რომელსაც QGIS-ში სინამდვილეში ვხვდებით (`QString`), თავი 10-ში გავეცნობით.

::: tip კოორდინატებისთვის
კოორდინატებს ყოველთვის `double`-ში ვინახავთ. QGIS-ის `QgsPointXY` შიგნით სწორედ ორ `double`-ს შეიცავს.
:::

## კოდი შედეგით

ახლა ცვლადებს ეკრანზე გამოვიტანთ. `std::cout` არის გამოტანის არხი (ქვეთავი 1.7-დან), ხოლო `<<` ჯაჭვივით აერთებს ერთმანეთზე გამოსატან ნაწილებს. `"\n"` ნიშნავს „ახალი ხაზი“.

```cpp coords.cpp
#include <iostream>

int main() {
    double lat = 41.7151;
    double lon = 44.8271;
    int vertexCount = 12;
    bool isValid = true;

    std::cout << "Tbilisi: " << lat << ", " << lon << "\n";
    std::cout << "Vertices: " << vertexCount << "\n";
    std::cout << std::boolalpha << "Valid: " << isValid << "\n";
    return 0;
}
```

```output
Tbilisi: 41.7151, 44.8271
Vertices: 12
Valid: true
```

`std::boolalpha` კომპიუტერს ეუბნება: `bool` გამოიტანე სიტყვით (`true`/`false`). მის გარეშე დაიბეჭდებოდა `1` ან `0`.

## const და auto

`const` (constant, „მუდმივა“) ნიშნავს, რომ მნიშვნელობას შემდეგ აღარ შევცვლით. `auto` კომპილატორს ეუბნება, რომ ტიპი თვითონ გამოიცნოს მარჯვენა მხარიდან.

```cpp
const double EARTH_RADIUS_KM = 6371.0;   // დედამიწის რადიუსი, არ იცვლება
auto area = 50.0;                         // კომპილატორი ხვდება: double
auto count = 12;                          // კომპილატორი ხვდება: int
```

::: warn ყურადღება
`const` ცვლადს მნიშვნელობა მხოლოდ შექმნისას ეძლევა. მოგვიანებით ცვლილების მცდელობა კომპილაციის შეცდომას იძლევა. ეს კარგია: შეცდომა კოდის გაშვებამდე ჩანს. QGIS-ის კოდში `const` ძალიან ხშირად გვხვდება (იხ. თავი 05).
:::

## მთელი რიცხვების გაყოფა

ეს პირველი ხაფანგია: როცა ორივე რიცხვი `int`-ია, გაყოფის შედეგიც `int`-ია და წილადი ნაწილი უბრალოდ იკვეთება.

```cpp division.cpp
#include <iostream>

int main() {
    int totalHectares = 7;
    int parcels = 2;

    std::cout << totalHectares / parcels << "\n";
    std::cout << totalHectares / 2.0 << "\n";
    return 0;
}
```

```output
3
3.5
```

ჯერ 7 ჰექტარი გავყავით 2 ნაკვეთზე და მივიღეთ `3` (არა `3.5`), რადგან ორივე რიცხვი მთელია. მეორე ხაზში `2.0` ათწილადია, ამიტომ მთელი გამოთვლა ათწილადებში ხდება და შედეგია `3.5`.

::: tip წესი
საშუალოს ან ფართობის გამოთვლისას დარწმუნდი, რომ ერთი მაინც `double`-ია, თორემ შედეგი „მოიჭრება“.
:::

## სიზუსტე და გარდაქმნა

კომპიუტერი ათწილადებს ორობით სისტემაში ინახავს და ზოგიერთ რიცხვს ზუსტად ვერ წარმოადგენს. ეს ისეთივე პრობლემაა, როგორც ათობით სისტემაში 1/3 = 0.3333…: უსასრულოა და სადმე უნდა შევწყვიტოთ. ამიტომ ორი ათწილადის `==`-ით შედარება სანდო არ არის.

```cpp precision.cpp
#include <iostream>
#include <cmath>

int main() {
    double a = 0.1 + 0.2;
    std::cout << std::boolalpha;
    std::cout << (a == 0.3) << "\n";
    std::cout << (std::abs(a - 0.3) < 1e-9) << "\n";

    int whole = static_cast<int>(3.99);
    std::cout << whole << "\n";
    return 0;
}
```

```output
false
true
3
```

ახსნა:
- `a == 0.3` სამართლიანად გვეპასუხება `false`, რადგან `0.1 + 0.2` კომპიუტერში ზუსტად `0.3` არ არის;
- `std::abs(a - 0.3) < 1e-9` ამოწმებს, მათ შორის სხვაობა 0.000000001-ზე ნაკლებია თუ არა (`std::abs` აბსოლუტური მნიშვნელობაა, `1e-9` კი 10⁻⁹) და პასუხია `true`;
- `static_cast<int>(3.99)` არის **აშკარა გარდაქმნა** ათწილადიდან მთელზე და ათწილადი ნაწილი უბრალოდ იკვეთება: `3`.

::: tip წესი
ათწილადები ვადარო სიზუსტით (`abs(a - b) < epsilon`). გარდაქმნა გააკეთე აშკარად, `static_cast<...>(...)`-ით, რომ ყველამ დაინახოს, სად იკარგება ინფორმაცია.
:::

## სავარჯიშო და შეჯამება

::: exercise სავარჯიშო
1. გამოაცხადე ცვლადები ბათუმისთვის: განედი `41.6168`, გრძედი `41.6367`, მოსახლეობა `int`-ად (მიახლოებით 170000). გამოიტანე ისინი.
2. წარმოიდგინე 5 ნაკვეთი, საერთო ფართობი 12 ჰექტარი. გამოთვალე საშუალო ფართობი სწორად (`double`) და არასწორად (`int`-ებით). შეადარე.
3. რას დაბეჭდავს `static_cast<int>(-2.7)`? ჯერ გამოიცანი, მერე შეამოწმე.
4. შეეცადე `const double PI = 3.14;`-ს მოგვიანებით შეცვლას და წაიკითხე კომპილატორის შეტყობინება.
:::

::: summary შეჯამება
- ცვლადი = სახელიანი ყუთი მეხსიერებაში; ტიპი = ყუთის ფორმა.
- ძირითადი ტიპები: `int`, `double`, `bool`, `char`, `std::string`.
- კოორდინატები — `double`, რაოდენობები — `int` ან `qint64`.
- `int / int` იძლევა `int`-ს.
- ათწილადებს ვადარებთ ზღვრით, არა `==`-ით.
- `const` = არ იცვლება; `auto` = ტიპს თვითონ გამოიცნობს.
:::
