წინამდებარე სახელმძღვანელოს მიზანია, მკითხველს დაეხმაროს QGIS-ის მომხმარებლობიდან მის პროგრამირებამდე გადასვლაში: QGIS-ის C++ API-ის დოკუმენტაციის (api.qgis.org) გააზრებასა და საკუთარი პროგრამული კოდის QGIS-ის ბირთვთან ინტეგრირების უნარის განვითარებაში.

წიგნი დაწერილია იმ მკითხველისთვის, რომელიც პროგრამირებას პირველად ეცნობა. წინასწარ საჭიროა მხოლოდ GIS-ის საბაზისო ცოდნა (ფენა, ობიექტი, კოორდინატი). Python-ისა და PyQGIS-ის ცოდნა სასარგებლოა, მაგრამ სავალდებულო არ არის: ყველა ტერმინი აქვე აიხსნება.

**ვერსიები.** წიგნის მაგალითები დაწერილია C++17 სტანდარტით. QGIS API-ის ხელმოწერები გადამოწმებულია `api.qgis.org`-ის 4.3.0-Master დოკუმენტაციასთან (Qt6); QGIS 3.x ვერსიებში (Qt5) ზოგი ხელმოწერა შეიძლება ოდნავ განსხვავდებოდეს. C++ მაგალითები თავები 02–09 არ საჭიროებს QGIS-ს; თავები 10–12 საჭიროებს Qt-ს და/ან QGIS-ს.

გამოცემაში განხილული ყველა პრაქტიკული მაგალითი ეფუძნება გეოგრაფიულ მონაცემებს და მოიცავს ისეთ ფუნდამენტურ კომპონენტებს, როგორებიცაა სივრცითი ფენები, გეოგრაფიული ობიექტები, კოორდინატები და სივრცითი მახასიათებლები (მაგალითად, ფართობები).

## რა არის პროგრამირება და რას ვსწავლობთ

**პროგრამა** არის ინსტრუქციების თანმიმდევრობა, რომელსაც კომპიუტერი ასრულებს. ინსტრუქციებს ვწერთ ტექსტად, სპეციალურ ენაზე. ამ ტექსტს **წყარო კოდი** (source code) ჰქვია, ენას კი **პროგრამირების ენა**.

::: analogy რეცეპტი
წყარო კოდი რეცეპტს ჰგავს: ნაბიჯ-ნაბიჯ წერია, რა გააკეთოს შემსრულებელმა. შემსრულებელი აქ კომპიუტერია, ის კი ზუსტად ასრულებს მხოლოდ იმას, რაც დაწერილია, და არაფერს ხვდება „თავისით“.
:::

QGIS არის GIS პროგრამა, რომელსაც ვიყენებთ რუკების სახატავად და სივრცითი ანალიზისთვის. ის თავადაც პროგრამაა და მისი კოდი ღიაა. მასთან პროგრამული გზით სამუშაოდ სამი დონე არსებობს:

| დონე | ენა | რა შეგვიძლია |
|---|---|---|
| 1. QGIS-ის Python კონსოლი და სკრიპტები | Python (PyQGIS) | გავაავტომატოთ განმეორებადი სამუშაო: ფენების დამუშავება, ექსპორტი |
| 2. პლაგინები | Python | დავამატოთ ახალი ღილაკები და ინსტრუმენტები |
| 3. QGIS-ის ბირთვი | C++ | შევცვალოთ ან გავაფართოვოთ თავად პროგრამა, ავაგოთ სწრაფი ან დახურული კომპონენტები |

ეს წიგნი მესამე დონისკენ გვატარებს: ვისწავლით C++-ს იმ მოცულობით, რაც QGIS-ის ბირთვის გასაგებად გვჭირდება.

### რა არის API

**API** (Application Programming Interface) არის „მენიუ“ პროგრამისტისთვის: ჩამონათვალი იმისა, რა ფუნქციები და კლასები აქვს ბიბლიოთეკას და როგორ გამოვიძახოთ ისინი. QGIS-ის API-ის აღწერა ვებგვერდზეა `api.qgis.org`. ამ წიგნის მთავარი მიზანია, ეს გვერდები გავიგოთ.

## PyQGIS და C++ API: ერთი ბირთვი, ორი ინტერფეისი

**PyQGIS** არის QGIS-ის Python-იდან გამოყენების საშუალება. ის ცალკე ბიბლიოთეკა არ არის. QGIS-ის ბირთვი C++-ზეა დაწერილი, Python-ის კლასები კი ძირითადად ავტომატურად გენერირდება (SIP-ის საშუალებით) იმავე C++ კლასებიდან. ამიტომ სახელები და ლოგიკა უმეტესად ერთი და იგივეა: `QgsVectorLayer`, `QgsFeature`, `QgsGeometry`.

::: note ზუსტად
ორი API ერთმანეთს ძირითადად ემთხვევა, მაგრამ იდენტური არ არის: ზოგი overload, ტიპი ან მეთოდი მხოლოდ C++-შია, ზოგი კი Python-ში სხვა ფორმით ჩანს. ამიტომ ბოლო სიტყვა ყოველთვის კონკრეტული ვერსიის დოკუმენტაციას ეკუთვნის.
:::

**ბიბლიოთეკა** (library) არის მზა კოდის ნაკრები, რომელსაც საკუთარ პროგრამაში ვიყენებთ, რომ ყველაფერი თავიდან არ დავწეროთ. **კლასი** (class) კი არის „ნახაზი“ რაიმე ობიექტისა (მაგალითად, ვექტორული ფენისა); კლასებს თავი 06-ში დაწვრილებით გავეცნობით.

### რა არის SIP?

**SIP (Python–C++ Binding Generator)** არის ინსტრუმენტი, რომელიც C++-ზე დაწერილი კლასებისა და ფუნქციების Python-იდან გამოყენების შესაძლებლობას უზრუნველყოფს. QGIS-ში SIP გამოიყენება C++ კლასებსა და Python ინტერფეისს შორის დამაკავშირებელი კოდის გენერირებისთვის.

QGIS-ის ბირთვი დაწერილია C++-ზე, ხოლო PyQGIS Python-იდან ამ ბირთვის ფუნქციონალზე წვდომის საშუალებას იძლევა. SIP-ის მეშვეობით იქმნება დამაკავშირებელი ფენა, რომლის საშუალებითაც Python-ის კოდიდან შესაძლებელია QGIS-ის C++ კლასებისა და მეთოდების გამოყენება.

მაგალითად, PyQGIS-ში შეგვიძლია გამოვიყენოთ შემდეგი კლასები:

- `QgsVectorLayer` — ვექტორული ფენის წარმოდგენა და მართვა;
- `QgsFeature` — გეოგრაფიული ობიექტის წარმოდგენა;
- `QgsGeometry` — გეომეტრიული მონაცემების წარმოდგენა და დამუშავება.

ეს კლასები QGIS-ის C++ API-ს შეესაბამება და Python-იდან მათი გამოყენება SIP-ის მიერ გენერირებული დამაკავშირებელი კოდის მეშვეობით ხდება.

**მნიშვნელოვანია:** SIP თავად არ არის PyQGIS და არც QGIS-ის ბირთვი. ის წარმოადგენს ერთ-ერთ ტექნოლოგიას, რომლის საშუალებითაც C++-ზე დაფუძნებული QGIS-ის ფუნქციონალი Python-იდან ხელმისაწვდომი ხდება.

::: analogy გზამკვლევი ორ ენაზე
წარმოიდგინე საქართველოს რუკა ორ ენაზე. ქალაქები და გზები ერთი და იგივეა, განსხვავდება მხოლოდ წარწერების ენა. PyQGIS არის „ქართული წარწერებით“ რუკა, C++ API — „ორიგინალის“.
:::

საბოლოოდ, QGIS-ის ძირითადი ლოგიკა (ფენა, ობიექტი, გეომეტრია) ორივე ენაში ერთია. C++-ში ახალია **გრამატიკა**: ტიპები, მაჩვენებლები, კომპილაცია. სწორედ მათ შევისწავლით.

## QGIS-ის არქიტექტურა

QGIS-ის წყარო კოდი რამდენიმე ბიბლიოთეკადაა დაყოფილი:

| საქაღალდე | ბიბლიოთეკა | რას შეიცავს | გეო-მაგალითი |
|---|---|---|---|
| `src/core/` | `qgis_core` | გეომეტრია, CRS, ფენები, ატრიბუტები, რენდერი | `QgsGeometry`, `QgsCoordinateReferenceSystem` |
| `src/gui/` | `qgis_gui` | ვიჯეტები და დიალოგები | ფენის არჩევის კომბობოქსი |
| `src/analysis/` | `qgis_analysis` | გეოპროცესინგი და ანალიზი | ბუფერი, გადაკვეთა |
| `src/app/` | `qgis` | თავად დესკტოპ პროგრამა | მენიუ, ინსტრუმენტთა პანელი |

::: tip დაიმახსოვრე
`core` არ იცნობს ინტერფეისს, `gui` კი `core`-ს ეყრდნობა. ამიტომაც შეგიძლია `core` ფანჯრების გარეშე, სერვერზეც გამოიყენო.
:::

### რას ნიშნავს `core` და `gui`

- `core` — QGIS-ის ძირითადი ფუნქციონალია: გეოგრაფიული მონაცემების დამუშავება, სივრცითი ფენები, გეომეტრიები, კოორდინატთა სისტემები და სხვა.
- `gui` — გრაფიკულ ინტერფეისთან დაკავშირებული ფუნქციონალია: რუკის ფანჯარა, დიალოგური ფანჯრები, ღილაკები და მომხმარებელთან ურთიერთქმედება.

### რას ნიშნავს „`core` არ იცნობს ინტერფეისს, `gui` კი `core`-ს ეყრდნობა“

ეს ნიშნავს, რომ `core`-ის ფუნქციონალი არ არის დამოკიდებული გრაფიკულ ინტერფეისზე. მას შეუძლია გეოგრაფიული მონაცემების დამუშავება ისე, რომ ეკრანზე რუკის ფანჯარა ან სხვა გრაფიკული ელემენტები საერთოდ არ არსებობდეს.

მეორე მხრივ, `gui` იყენებს `core`-ის შესაძლებლობებს, რათა ეს მონაცემები მომხმარებლისთვის ვიზუალურად წარმოადგინოს და მათთან ინტერაქცია უზრუნველყოს.

| შრე | რას შეიცავს | მიმართულება |
|---|---|---|
| **GUI** | რუკის ჩვენება, ღილაკები, დიალოგები | იყენებს `core`-ს ↓ |
| **Core** | ფენები, გეომეტრიები, სივრცითი გამოთვლები | არ იცნობს `gui`-ს |

დამოკიდებულების მიმართულება: **GUI → Core**. `core`-ს GUI არ სჭირდება.

### რატომ არის ეს მნიშვნელოვანი

წარმოიდგინე, რომ გჭირდება ერთი მილიონი გეოგრაფიული ობიექტის დამუშავება სერვერზე, რუკის ფანჯრის გახსნის გარეშე. `core`-ის გამოყენებით შეგიძლია:

- წაიკითხო გეოგრაფიული ფენები;
- გამოთვალო ფართობები და მანძილები;
- გაფილტრო გეოგრაფიული ობიექტები;
- დაამუშაო მონაცემები და შეინახო შედეგები.

ამ ამოცანებისთვის გრაფიკული ინტერფეისი საჭირო არ არის. მაგალითად, PyQGIS-ში:

```python
from qgis.core import QgsApplication, QgsVectorLayer

# QGIS-ის ინიციალიზაცია გრაფიკული ინტერფეისის გარეშე
app = QgsApplication([], False)
app.initQgis()

# ვექტორული ფენის შექმნა
layer = QgsVectorLayer(
    "/data/roads.gpkg|layername=roads",
    "roads",
    "ogr"
)

if layer.isValid():
    print("ფენა წარმატებით ჩაიტვირთა")
    print("ობიექტების რაოდენობა:", layer.featureCount())

app.exitQgis()
```

აქ `QgsApplication([], False)` მიუთითებს, რომ QGIS გრაფიკული ინტერფეისის გარეშე მუშაობს. ამას ხშირად **headless** რეჟიმს უწოდებენ.

::: note შენიშვნა
გრაფიკული ინტერფეისის გარეშე მუშაობა არ ნიშნავს, რომ QGIS-ის ინიციალიზაცია აღარ გვჭირდება. საჭიროა გარემოს სწორად მომზადება, ხოლო კონკრეტული ოპერაციებისთვის შესაძლოა დამატებითი დამოკიდებულებებიც იყოს საჭირო.
:::

::: tip რა უნდა დაიმახსოვრო
- `qgis.core` შეიცავს QGIS-ის ძირითად ფუნქციონალს.
- `qgis.gui` შეიცავს გრაფიკულ ინტერფეისთან დაკავშირებულ ფუნქციონალს.
- `gui` იყენებს `core`-ს, მაგრამ `core` არ არის დამოკიდებული `gui`-ზე.
- ამიტომ `core`-ის გამოყენება შესაძლებელია სერვერზე და გრაფიკული ინტერფეისის გარეშე, სათანადო ინიციალიზაციის პირობებში.
:::

მთავარი აზრი: QGIS მხოლოდ დესკტოპ-აპლიკაცია არ არის. მისი ძირითადი გეოსივრცითი ფუნქციონალი შეიძლება გამოიყენო სერვერულ პროგრამებში, ავტომატიზაციის სკრიპტებსა და მონაცემთა დამუშავების სამუშაო პროცესებში.

## ერთი და იგივე ამოცანა ორ ენაზე

ამოცანა: ფენის ყველა ობიექტის სახელის გამოტანა. ჯერ ტერმინები, რომლებსაც კოდში შევხვდებით:

| ტერმინი | რას ნიშნავს |
|---|---|
| ფენა (`layer`) | მონაცემთა ერთი ნაკრები რუკაზე, მაგალითად მდინარეების ფენა |
| ობიექტი (`feature`) | ფენის ერთი ჩანაწერი: გეომეტრია და ატრიბუტები, მაგალითად ერთი მდინარე |
| ატრიბუტი | ობიექტის ერთი თვისება, მაგალითად `name` ველი |
| იტერატორი (`iterator`) | „მომხსენებელი“, რომელიც ფენის ობიექტებს სათითაოდ გვაწვდის |

პირველად ვნახოთ იგივე ლოგიკა C++-ში. თითოეული ხაზი ცალკე აიხსნება:

```cpp
QgsVectorLayer *layer =
  qobject_cast<QgsVectorLayer *>(iface->activeLayer());   // 1
QgsFeatureIterator it = layer->getFeatures();            // 2
QgsFeature feature;                                       // 3
while (it.nextFeature(feature)) {                         // 4
  qDebug() << feature.attribute("name").toString();       // 5
}
```

1. ვიღებთ რუკაზე ახლა არჩეულ ფენას და ვაცხადებთ, რომ ის ვექტორული ფენაა (`*` და `qobject_cast` თავებში 04 და 07 აიხსნება);
2. ფენას ვთხოვთ ობიექტების იტერატორს;
3. ვქმნით ცარიელ ობიექტს, რომელშიც თითოეულს ჩავწერთ;
4. სანამ ახალი ობიექტი არსებობს (`nextFeature`), ციკლი მეორდება;
5. ვბეჭდავთ ობიექტის `name` ატრიბუტს.

თუ Python-ს იცნობ, იგივე შედეგი შედარებისთვის:

::: compare
```python
layer = iface.activeLayer()
for feature in layer.getFeatures():
    print(feature["name"])
```

```cpp
QgsVectorLayer *layer =
  qobject_cast<QgsVectorLayer *>(iface->activeLayer());
QgsFeatureIterator it = layer->getFeatures();
QgsFeature feature;
while (it.nextFeature(feature)) {
  qDebug() << feature.attribute("name").toString();
}
```
:::

ორივეგან ერთი და იგივე სახელებია (`getFeatures`, `attribute`). C++-ში ემატება ტიპები (`QgsVectorLayer`), `*` ნიშანი, `;` ყოველი ინსტრუქციის ბოლოს და ტიპის გარდაქმნა `qobject_cast`. თითოეულს ამ წიგნში ცალკე გავარჩევთ.

## როგორ მუშაობს კომპილაცია

კომპიუტერი პირდაპირ ვერ კითხულობს ადამიანის დაწერილ ტექსტს. მას სჭირდება **მანქანური კოდი**, ანუ ნულებისა და ერთიანების თანმიმდევრობა.

C++ პროგრამა **კომპილდება**: წყარო კოდს **კომპილატორი** (compiler) გადააქცევს ერთ ფაილად, რომელსაც კომპიუტერი უშუალოდ ასრულებს. ამ ფაილს **შესრულებადი ფაილი** (executable) ჰქვია, Windows-ზე ის `.exe`-ა.

```
წყარო კოდი (.cpp)  →  კომპილატორი  →  შესრულებადი ფაილი  →  გაშვება
```

::: analogy თარგმანი
წარმოიდგინე წიგნი, რომელიც ქართულად დაწერე. კომპილატორი პროფესიონალი მთარგმნელია: მთელ წიგნს წინასწარ თარგმნის და გიბრუნებს გამზადებულ ინგლისურ ვერსიას. ამის შემდეგ მკითხველი უკვე მზა ტექსტს კითხულობს. მთარგმნელი მეტს აღარ სჭირდება.
:::

სინამდვილეში აწყობას ორი ნაწილი აქვს: **კომპილაცია** (თითოეული `.cpp` ფაილი ცალკე გადადის მანქანურ კოდად) და **ლინკირება** (linking), როცა ეს ნაწილები და საჭირო ბიბლიოთეკები ერთ შესრულებად ფაილად ერთდება. გაშვებისას პროგრამას შეიძლება კიდევ დასჭირდეს **დინამიური ბიბლიოთეკები** (`.dll`, `.so`), რომლებიც ცალკე ფაილებად ინახება და გაშვებისას იტვირთება.

ამიტომ პროცესს ორი ეტაპი აქვს: ჯერ **აწყობა** (build), შემდეგ **გაშვება** (run). თუ კოდში შეცდომაა, კომპილატორი აწყობისას გვეტყვის და პროგრამა საერთოდ არ შეიქმნება. ეს კარგია: შეცდომა ჩანს, სანამ ვინმე პროგრამას გამოიყენებს.

::: note ინტერპრეტატორი
Python-ს თარგმნა არ სჭირდება მანამ, სანამ ვუშვებთ: პროგრამა სახელწოდებით **ინტერპრეტატორი** კოდს ხაზ-ხაზ კითხულობს და მაშინვე ასრულებს. ეს მოხერხებულია, თუმცა უფრო ნელია, ხოლო კოდის ტექსტი გამშვებ პირთან რჩება.
:::

## სამუშაო გარემოს მომზადება

C++ კოდის დასაწერად და გასაშვებად გჭირდება სამი რამ:

| რა | რისთვის | მაგალითი |
|---|---|---|
| **რედაქტორი** | კოდის წასაკითხად და დასაწერად | Visual Studio Code, Qt Creator |
| **კომპილატორი** | კოდის გადასაყვანად | `g++` (GCC) |
| **ტერმინალი** | ბრძანებების აკრეფისთვის | PowerShell, Linux ტერმინალი |

**Linux-ზე** (Ubuntu/Debian) კომპილატორის დასაყენებლად:

```bash
sudo apt install g++
g++ --version
```

**Windows-ზე** უმარტივესია MSYS2 (msys2.org): დააყენე და მის ტერმინალში გაუშვი `pacman -S mingw-w64-ucrt-x86_64-gcc`. შემდეგ `C:\msys64\ucrt64\bin` დაამატე სისტემის `Path`-ში და ახალ ტერმინალში შეამოწმე `g++ --version`. თუ ვერსია დაიბეჭდა, გარემო მზადაა.

::: tip თუ ვერ დააყენე
დასაწყისისთვის კოდის გასაშვებად შეგიძლია გამოიყენო ონლაინ კომპილატორი (მაგალითად, onlinegdb.com ან godbolt.org). თავები 02–10 არ საჭიროებს QGIS-ის დაყენებას.
:::

## პირველი C++ პროგრამა

შექმენი ფაილი `main.cpp` და ჩაწერე:

```cpp main.cpp
#include <iostream>

int main() {
    std::cout << "Hello, Georgia!" << std::endl;
    return 0;
}
```

ტერმინალში, იმავე საქაღალდეში:

```bash
g++ main.cpp -o hello
./hello
```

პირველი ბრძანება აკომპილებს `main.cpp`-ს და ქმნის შესრულებად ფაილს `hello`-ს (`-o` არის „გამოსასვლელი ფაილის სახელი“). მეორე ბრძანება მას უშვებს. (Windows PowerShell-ში გაუშვი `.\hello.exe`.)

```output
Hello, Georgia!
```

### ხაზ-ხაზ

| ხაზი | რას აკეთებს |
|---|---|
| `#include <iostream>` | „ჩაიტვირთე სტანდარტული ბიბლიოთეკის ნაწილი, რომელიც ეკრანზე ტექსტის გამოტანას ემსახურება“ |
| `int main() { ... }` | პროგრამის შესასვლელი წერტილი: აქედან იწყება შესრულება. `int` ნიშნავს, რომ ფუნქცია მთელ რიცხვს დააბრუნებს |
| `std::cout << "..."` | ტექსტის გამოტანა ეკრანზე. `<<` „ატარებს“ ტექსტს გამოსატან არხში |
| `std::endl` | ახალ ხაზზე გადასვლა |
| `return 0;` | პროგრამა მუშაობას ამთავრებს და ატყობინებს, რომ ყველაფერი რიგზეა (`0` = წარმატება) |
| `;` | ყოველი ინსტრუქციის დამასრულებელი ნიშანი |

::: warn ხშირი შეცდომები
პროგრამა არ აიწყობა, თუ `;` გამოგრჩა, ფიგურული ფრჩხილი `}` დაგავიწყდა ან `main`-ის სახელი შეცდომით დაწერე. კომპილატორის შეტყობინებაში ყოველთვის წაიკითხე ხაზის ნომერი: ის გიჩვენებს, სად უნდა დაიწყო ძებნა.
:::

## Python vs C++ ერთი შეხედვით

ცხრილი მათთვის, ვინც Python-ს იცნობს. თუ არ იცნობ, უბრალოდ გაიგე, რა არის C++-ის მხარე:

| | Python / PyQGIS | C++ / QGIS Core |
|---|---|---|
| გაშვება | ინტერპრეტატორი, პირდაპირ | კომპილაცია, შემდეგ გაშვება |
| ტიპები | დინამიური: `x = 5` | სტატიკური: `int x = 5;` |
| მეხსიერება | ავტომატური | ხელით, ან smart pointer-ებით |
| შეცდომები | გაშვების დროს | უმეტესად კომპილაციისას |
| სიჩქარე | ხშირად ნელი, მოხერხებული | ხშირად მაღალი, მაგრამ დამოკიდებულია კოდზე (C++ ავტომატურად სწრაფი არ არის) |
| კოდის სახე | `.py` ღია ტექსტია | შედეგი ბინარულია; წყარო კოდის აღდგენა რთულია, მაგრამ შეუძლებელი არა |

## სავარჯიშო და შეჯამება

::: exercise სავარჯიშო
1. გახსენი `api.qgis.org`, მოძებნე კლასი `QgsFeature` და ჩამოწერე სამი მეთოდის სახელი.
2. დააყენე კომპილატორი და გაუშვი `g++ --version`.
3. დაწერე და გაუშვი „Hello“ პროგრამა, ოღონდ გამოიტანე შენი ქალაქის სახელი.
4. დაამატე მეორე ხაზი: `Population: 1100000` (თბილისის მიახლოებითი მოსახლეობა).
5. განზრახ წაშალე ერთი `;` და წაიკითხე კომპილატორის შეტყობინება.
:::

::: summary შეჯამება
- პროგრამა = ინსტრუქციები; წყარო კოდი = ამ ინსტრუქციების ტექსტი.
- API არის ბიბლიოთეკის „მენიუ“; QGIS-ის API-ის აღწერა `api.qgis.org`-ზეა.
- PyQGIS და C++ API ერთი და იგივე კლასებია სხვადასხვა ენაზე.
- `core` — ლოგიკა, `gui` — ინტერფეისი, `app` — პროგრამა.
- C++ კოდი იკომპილება: წყარო კოდი → კომპილატორი → შესრულებადი ფაილი.
:::
