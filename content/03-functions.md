პროგრამა დიდია და ერთსა და იმავე გამოთვლას ბევრგან ვიყენებთ. თუ ყოველ ჯერზე თავიდან ვწერთ, კოდი იზრდება და შეცდომებიც მატულობს. ამიტომ განმეორებადი ნაწილი ერთხელ ვწერთ და სახელს ვარქმევთ. ასეთ დასახელებულ ნაწილს **ფუნქცია** ჰქვია.

## რა არის ფუნქცია

::: analogy ხელსაწყო
ფუნქცია არის ხელსაწყო, რომელსაც რაღაცას აწვდი (შესასვლელი) და რაღაცას გიბრუნებს (გამოსასვლელი). ფართობის გამოთვლის ხელსაწყოს სიგანესა და სიგრძეს აძლევ და ფართობს იღებ. შიგნით როგორ მუშაობს, გამოძახებისას არ გვაინტერესებს.
:::

ფუნქციის დაწერა ორი მიზნით გვჭირდება: ერთი და იგივე კოდი ბევრგან არ გავიმეოროთ და პროგრამა დავყოთ ადვილად გასაგებ ნაწილებად. ბრძანება `main()`, რომელსაც ხშირად ვხვდებით, ასევე ფუნქციაა, პროგრამის მთავარი ფუნქცია.

## ფუნქციის ანატომია

```cpp
double calculateArea(double width, double height) {
    return width * height;
}
```

| ნაწილი | მაგალითში | მნიშვნელობა |
|---|---|---|
| დაბრუნების ტიპი | `double` | რა სახის მნიშვნელობას დაგიბრუნებს |
| სახელი | `calculateArea` | როგორ გამოვიძახოთ |
| პარამეტრები | `double width, double height` | რა უნდა გადავცეთ (თითოეულს ტიპი აქვს) |
| სხეული | `{ ... }` | რას აკეთებს ფუნქცია |
| `return` | `return width * height;` | უბრუნებს შედეგს გამომძახებელს და ამთავრებს ფუნქციას |

გამოძახება ასე ხდება: `calculateArea(5.0, 10.0)`. ფრჩხილებში გადაცემულ მნიშვნელობებს **არგუმენტები** ეწოდება, ფუნქციის ხელმოწერაში მათ **პარამეტრები** ჰქვია. თუ ფუნქცია არაფერს აბრუნებს, დაბრუნების ტიპია `void` („არაფერი“).

::: warn გავრცელებული შეცდომა
ფუნქციის განსაზღვრისას ფრჩხილების შემდეგ `;` არ დაიდება: `double f(double a); { ... }` არასწორია. `;` ფუნქციას „დეკლარაციად“ აქცევს და ფიგურული ფრჩხილები ფუნქციას აღარ ეკუთვნის.
:::

## namespace — სახელების საქაღალდე

წარმოიდგინე დიდი პროექტი, სადაც ორ სხვადასხვა ბიბლიოთეკას ორივეს აქვს ფუნქცია `calculateArea`. კომპილატორმა როგორ უნდა გაარჩიოს? ამ პრობლემას **namespace** ხსნის.

::: analogy საქაღალდეები კომპიუტერში
ორ საქაღალდეში (`ProjectA`, `ProjectB`) შეიძლება ერთი სახელის ფაილი გვქონდეს, `data.txt`. კონფლიქტი არ იქნება, რადგან მისამართი განსხვავებულია. `namespace` სწორედ ასეთი საქაღალდეა კოდისთვის.
:::

```cpp area.cpp
#include <iostream>

namespace GIS {
    double calculateArea(double width, double height) {
        return width * height;
    }
}

int main() {
    double area = GIS::calculateArea(5.0, 10.0);
    std::cout << "Area: " << area << std::endl;
    return 0;
}
```

```output
Area: 50
```

აქ ფუნქცია `GIS` namespace-შია მოთავსებული. მისი გამოძახებისას ვწერთ `GIS::calculateArea(...)`.

`::` სახელდება **scope resolution operator** და ნიშნავს „შედი ამ namespace-ში და იქიდან აიღე“. იგივე იდეაა `std::cout`-ში, რომელსაც ისედაც ვიყენებდით: `std` არის C++-ის სტანდარტული ბიბლიოთეკის namespace-ის სახელი (standard), `cout` კი მასში მოთავსებული ობიექტი.

::: tip QGIS-ში
`Qgis::WkbType`, `Qgis::DistanceUnit` — ეს `Qgis` namespace-ია. კლასებს კი `Qgs` პრეფიქსი აქვთ: `QgsFeature`, `QgsProject`. პრეფიქსიც ერთგვარი namespace-ია ძველი სტილით.
:::

## overload — ერთი სახელი, სხვადასხვა პარამეტრები

C++-ში ერთსა და იმავე სახელზე რამდენიმე ფუნქცია შეიძლება არსებობდეს, თუ პარამეტრები განსხვავდება. ამას **overload** (გადატვირთვა) ჰქვია. კომპილატორი თავად ირჩევს სწორს არგუმენტების რაოდენობისა და ტიპის მიხედვით.

```cpp overload.cpp
#include <iostream>

namespace GIS {
    double calculateArea(double width, double height) {
        return width * height;                 // მართკუთხედი
    }
    double calculateArea(double radius) {
        return 3.14159 * radius * radius;      // წრე
    }
}

int main() {
    std::cout << GIS::calculateArea(5.0, 10.0) << "\n";
    std::cout << GIS::calculateArea(10.0) << "\n";
    return 0;
}
```

```output
50
314.159
```

პირველი გამოძახება ორი არგუმენტითაა და მართკუთხედის ვერსიას იღებს, მეორე ერთი არგუმენტით და წრის ვერსიას. QGIS-ის API სავსეა ასეთი overload-ებით: მაგალითად, `QgsPointXY` რამდენიმე სხვადასხვა გზით იქმნება.

## default პარამეტრი

პარამეტრს შეიძლება ჰქონდეს ნაგულისხმევი მნიშვნელობა. თუ არგუმენტს არ გადავცემთ, ის გამოიყენება.

```cpp units.cpp
#include <iostream>

double toMeters(double value, double factor = 1.0) {
    return value * factor;
}

int main() {
    std::cout << toMeters(2.5, 1000.0) << "\n";   // კილომეტრი -> მეტრი
    std::cout << toMeters(7.0) << "\n";            // უკვე მეტრებშია
    return 0;
}
```

```output
2500
7
```

პირველ გამოძახებაში ვაძლევთ 2.5 კმ-ს და გადამყვან კოეფიციენტს 1000. მეორეში კოეფიციენტი არ გადაგვიცია და გამოიყენა `1.0`. default მნიშვნელობა მხოლოდ ბოლო პარამეტრებს შეიძლება ჰქონდეთ. ეს QGIS-ში ძალიან გავრცელებულია, მაგალითად `getFeatures()` პარამეტრის გარეშეც გამოიძახება.

## მანძილი ორ წერტილს შორის

```cpp distance.cpp
#include <iostream>
#include <cmath>

namespace GIS {
    double distance(double x1, double y1, double x2, double y2) {
        return std::hypot(x2 - x1, y2 - y1);
    }
}

int main() {
    std::cout << GIS::distance(0.0, 0.0, 3.0, 4.0) << "\n";
    return 0;
}
```

```output
5
```

`std::hypot(a, b)` არის `√(a² + b²)`, ანუ პითაგორას თეორემა: მანძილი გეგმურ (დეკარტულ) კოორდინატებში. წერტილები (0,0) და (3,4) სამკუთხედის გვერდებია 3 და 4, ჰიპოტენუზა კი 5. `<cmath>` არის მათემატიკური ფუნქციების ბიბლიოთეკა.

## .h და .cpp ფაილები

დიდ პროექტში ფუნქციის **დეკლარაცია** (რა ჰქვია, რა აქვს შესასვლელში და გამოსასვლელში) და **განსაზღვრება** (როგორ მუშაობს) ცალკე ფაილებშია:

- **`.h` (header) ფაილი** — დეკლარაცია, ერთგვარი „სარჩევი“; მას სხვა ფაილები იყენებენ;
- **`.cpp` ფაილი** — განსაზღვრება, თავად კოდი.

QGIS-ის მთელი წყარო კოდი ასეა აგებული, `api.qgis.org` კი სწორედ `.h` ფაილებიდან გენერირდება. ამიტომაც ამ ფაილებს ხშირად წაიკითხავ.

```cpp gis_utils.h
#pragma once

namespace GIS {
    double distance(double x1, double y1, double x2, double y2);
}
```

```cpp gis_utils.cpp
#include "gis_utils.h"
#include <cmath>

double GIS::distance(double x1, double y1, double x2, double y2) {
    return std::hypot(x2 - x1, y2 - y1);
}
```

```cpp main.cpp
#include <iostream>
#include "gis_utils.h"

int main() {
    std::cout << GIS::distance(0.0, 0.0, 3.0, 4.0) << "\n";
}
```

ორივე `.cpp` ფაილი ერთად უნდა დაკომპილდეს:

```bash
g++ main.cpp gis_utils.cpp -o gis
```

::: note
`#include <...>` — სისტემური ბიბლიოთეკა, `#include "..."` — შენი საკუთარი ფაილი. `#pragma once` იცავს header ფაილს ორჯერ ჩართვისგან.
:::

## სავარჯიშო და შეჯამება

::: exercise სავარჯიშო
1. დაწერე `GIS::perimeter(double width, double height)` (მართკუთხა ნაკვეთის პერიმეტრი) და შეამოწმე 5 × 10 ზომაზე (უნდა მიიღო 30).
2. დაამატე overload კვადრატისთვის: `perimeter(double side)`.
3. გამოთვალე მანძილი წერტილებს შორის (2, 3) და (6, 6) (უნდა მიიღო 5).
4. გადაიტანე ფუნქციები `gis_utils.h` / `gis_utils.cpp` ფაილებში და გაუშვი.
:::

::: summary შეჯამება
- ფუნქცია = ერთხელ დაწერილი, სახელდებული ინსტრუქციათა ნაკრები; ის იღებს არგუმენტებს და აბრუნებს შედეგს.
- ფუნქცია = დაბრუნების ტიპი + სახელი + ტიპიზებული პარამეტრები.
- `namespace` იცავს სახელებს კონფლიქტისგან, `::` მასში შედის.
- overload და default პარამეტრები QGIS API-ში ყველგანაა.
- `.h` — დეკლარაცია, `.cpp` — განსაზღვრება.
:::
